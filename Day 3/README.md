# Generative AI – Advanced Concepts and Projects

## 📌 Overview

This repository contains hands-on learning projects focused on advanced Generative AI concepts, including LangGraph, LangSmith, AI Agents using Groq, and Multi-Model Agents.

These projects explore how to build AI-powered applications, manage agent workflows, monitor AI applications, and work with multiple language models.

## 📂 Projects

### 1. LangGraph

**Description:**  
Exploring LangGraph, a framework for building stateful, multi-step AI agent workflows. It helps create applications where different processing steps are connected through a graph-based structure.

**Key Concepts:**
- Introduction to LangGraph
- Graph-based workflows
- Nodes and edges
- State management
- AI agent workflows

**Google Colab:**  
[Open LangGraph Notebook](https://colab.research.google.com/drive/1TRWUSWQmrj_Ycogb6OZEQTfBBL5zF-GG)

---

### 2. LangSmith

**Description:**  
Learning LangSmith for debugging, tracing, monitoring, and evaluating LLM-powered applications. It helps developers understand how AI applications execute and identify issues in their workflows.

**Key Concepts:**
- Introduction to LangSmith
- LLM application tracing
- Debugging AI workflows
- Monitoring model execution
- Evaluation and performance analysis

**Google Colab:**  
[Open LangSmith Notebook](https://colab.research.google.com/drive/1fhNicye6ngxs6uDu1j6fTxw-dADKkE3g)

---

### 3. AI Agent Using Groq

**Description:**  
Building an AI agent powered by Groq, exploring how an LLM can understand user queries and generate intelligent responses.

**Key Concepts:**
- Introduction to AI Agents
- Groq API integration
- LLM-powered applications
- Prompt engineering
- AI agent interaction

**Google Colab:**  
[Open AI Agent Using Groq Notebook](https://colab.research.google.com/drive/1j6kUUJDSaQsqbZc-HUf-aeFwqR28xj_D)

### 4. Multi-Model Agent

**Description:**  
Exploring a multi-model AI agent approach that works with multiple AI models. This project focuses on understanding how different models can be used within an agent-based application.

**Key Concepts:**
- Multi-model AI systems
- Working with multiple LLMs
- Model selection and interaction
- AI agent architecture
- LLM integration
